ปรับหน้าตา MAX Agent ให้กดง่ายและอ่านชัดขึ้น

เทียบจากหน้าจอปัจจุบันใน index.html และหน้าแชร์ลูกค้า ใช้กฎเรื่องตัวหนังสือ ระยะห่าง สี จุดสัมผัส ปุ่ม และการเคลื่อนไหวจากชุดข้อมูล ui-ux-pro-max เป็นตัวตั้ง แล้วคงสีแบรนด์ #c2552d ชื่อคอนโดภาษาอังกฤษ ข้อความไทย เมนูล่าง 5 ช่อง และโครงคอมแบบแถบซ้ายไว้เหมือนเดิม

มีสามแบบให้สลับด้านล่าง สีเน้นยังเป็น #c2552d ทุกแบบ เมนูล่างและแถบซ้ายของคอมเหมือนกัน หน้าแชร์เลื่อนรูปเองทุก 3 วินาที พร้อมปัดนิ้ว ปุ่มก่อนหน้า ถัดไป และหยุด

แบบ A: การ์ดอุ่นสองคอลัมน์ ตัวหนังสืออ่านชัด และกดได้เต็มคำ

8 จุดที่ควรปรับ

  1. 1ปุ่มเล็กเกินนิ้ว

    ตอนนี้ ชิปตัวกรองสูง 30px ดาวบนรูป 28px ปุ่มในการ์ดประมาณ 30px ปุ่มปิดตัวกรองประมาณ 32px ชิปห้องน้ำ 38px

    ปรับแล้ว จุดสัมผัสอย่างน้อย 44px และห่างกัน 8px

    เพราะ แอปนี้ใช้บนไอโฟน เป้าที่เล็กกว่า 44px ทำให้นิ้วกดพลาด

  2. 2ตัวหนังสือเล็กไป

    ตอนนี้ เมนูล่าง 10px ป้ายสถานะและวันที่ 10px จำนวนรูป 9px รายละเอียดการ์ด 11px ข้อความท้ายหน้าแชร์ 11px

    ปรับแล้ว ข้อความประกอบไม่ต่ำกว่า 12px ข้อความทั่วไป 14–16px ราคา 18px ระยะบรรทัด 1.5

    เพราะ ภาษาไทยอ่านยากเมื่อเล็กกว่า 12px

  3. 3สีจาง อ่านไม่ชัด

    ตอนนี้ ข้อความสี #8e8680 บนขาวได้ 3.58:1 เมนูล่าง #8a8078 ได้ 3.86:1 ชิปที่เลือกในตัวกรอง (#c2552d บนพื้น #fbeee8) ได้ 3.99:1 ปุ่มรูปที่ปิดใช้ #aaa บน #eee ได้ 2:1 สถานะเขียว #1a8a4a ได้ 4.39:1 เกณฑ์ตัวหนังสือปกติคือ 4.5:1

    ปรับแล้ว ข้อความรองเป็น #5c534c (7.5:1) ตัวหนังสือแบรนด์ขนาดเล็กเป็น #8f3d1f (7.3:1) ชิปที่เลือกใช้ตัวเข้มบนพื้นอ่อนพร้อมเครื่องหมายถูก สถานะว่างใช้เขียว #1f7a3a ปุ่มพื้นแบรนด์ยังเป็น #c2552d ตัวหนังสือขาวได้ 4.53:1

    เพราะ ตัวเลขและสถานะต้องอ่านได้กลางแดด และคนที่แยกสีไม่ชัดต้องไม่พึ่งสีอย่างเดียว

  4. 4ระยะห่างไม่เป็นจังหวะ

    ตอนนี้ ในการ์ดเว้นบรรทัดแค่ 1px ขอบใน 8–9px ชิปห่าง 6px

    ปรับแล้ว ใช้ขั้น 4 และ 8px ขอบในการ์ด 12px ช่องระหว่างกลุ่มในตัวกรอง 16px

    เพราะ ระยะเท่ากันทำให้กวาดตาหาราคาได้เร็ว โดยไม่ต้องเปลี่ยนโครงหน้ารายการ

  5. 5อิโมจิแทนไอคอน

    ตอนนี้ ทักทายมี 👋 ชิปน่าสนใจมี ⭐ หน้าแชร์มี 📷 และ 📍 ไอคอนพวกนี้ขนาดและสีไม่เท่ากันระหว่างไอโฟนกับแมค

    ปรับแล้ว ใช้ไอคอนเส้นชุดเดียวกัน และปุ่มที่มีแต่รูปมีชื่อสำหรับโปรแกรมอ่านหน้าจอ

    เพราะ อิโมจิคุมสีและขนาดไม่ได้ และไม่ควรเป็นตัวบอกสถานะ

  6. 6ตัวกรองบอกสถานะไม่ครบ

    ตอนนี้ ช่องขนาดพื้นที่ไม่มีป้าย เหลือแค่คำจางในช่องซึ่งหายตอนเริ่มพิมพ์ ชิปที่เลือกเปลี่ยนแค่สี แถบสรุปตัวกรองในโค้ดถูกซ่อนด้วย display:none

    ปรับแล้ว มีป้าย “ต่ำสุด / สูงสุด” ชิปที่เลือกมีเครื่องหมายถูกและสถานะ aria-pressed แถบ “กำลังกรอง” โชว์ใต้ชิป พร้อมปุ่มล้าง

    เพราะ คนที่ใช้คีย์บอร์ดและโปรแกรมอ่านหน้าจอต้องรู้ว่าเลือกอะไรอยู่ ไม่ใช่เดาจากสี

  7. 7การ์ดห้องกดยากและคำถูกตัด

    ตอนนี้ รูปไม่มีคำอธิบาย ปุ่ม “คัดข้อความ” กว้างไม่พอจนคำถูกตัด ห้องที่ไม่มีรูปยังกดปุ่มรูปได้แต่เป็นสีเทาจาง จุดโฟกัสคีย์บอร์ดถูกเอาออก และหน้าแรกห้ามซูมด้วย maximum-scale=1

    ปรับแล้ว รูปตัวอย่างมีคำอธิบาย บนจอแคบปุ่มสองปุ่มเรียงลงมาให้คำอ่านครบและสูง 44px ห้องไม่มีรูปขึ้นว่า “ยังไม่มีรูป” และกดไม่ได้ มีวงโฟกัสชัด หน้านี้ซูมได้ ลำดับข้อมูลในการ์ดยังเป็นชื่อ วันที่ ประเภท ราคา สถานีเหมือนเดิม

    เพราะ การ์ดคืองานหลักของเอเจนต์ ต้องกดคัดข้อความได้จริงทั้งนิ้วและคีย์บอร์ด

  8. 8การเคลื่อนไหวไม่มีการควบคุม

    ตอนนี้ การ์ดลอยขึ้นเมื่อเอาเมาส์ไปชี้ ซึ่งนิ้วบนไอโฟนไม่ได้ชี้ หน้าแชร์เลื่อนรูปเองทุก 3 วินาทีโดยไม่มีปุ่มหยุด และไม่ได้ดูค่า prefers-reduced-motion

    ปรับแล้ว กดปุ่มแล้วเปลี่ยนความทึบใน 120ms รูปแชร์เลื่อนเองทุก 3 วินาที มีปุ่มก่อนหน้า ถัดไป และหยุด และปัดด้วยนิ้วได้ ถ้าเครื่องตั้งค่าลดการเคลื่อนไหว รูปจะไม่เลื่อนเอง

    เพราะ ของที่ขยับเองทำให้เวียนหัว และคนที่ใช้เมาส์บนแมคต้องเห็นโฟกัสไม่ใช่แค่ตอนเอาเมาส์ไปชี้
